# BNO055 校正觀察與姿態補測報告（2026-08-31）

## 報告目的與證據邊界

本報告保存兩次獨立 BNO055 桌面測試的可追溯結論：780 秒校正狀態觀察，以及
後續 300 秒直立方向補測。兩次 session 不合併計數，也不把後一次結果回寫成
前一次的歷史結果。

本階段只驗證主機記錄到的融合資料、順序式中文引導、相反直立方向及回復平放
的資料現象。操作者 token 是操作陳述，不是獨立姿態真值；沒有外部量具、治具
角度基準或車身座標參考。因此本文不宣稱角度精度、完整六面精度、axis remap、
車身座標、校正保存／載入／跨重啟、道路動態或警示決策整合已完成。

描述性平均向量比較：

- 測距模組端朝上／朝下：正規化內積 `-0.992155`，夾角 172.818°。
- 測距模組端朝下／起始平放：夾角 77.881°。
- 起始／結束平放：夾角 1.043°。

Raw measurement timestamp 在 BNO055 block read 前取得；marker 時間是 wrapper
事件發生時的 host monotonic。兩者使用同一主機 monotonic 時基，但 measurement
仍需經過 I2C read、格式化及 pipe 傳遞，故窗口邊界可能相差約一筆。第一筆
資料可觀察到 raw timestamp 與 wrapper receive time 相差約 7.34 ms。另排除
每個窗口首尾各 1 秒後，朝上／朝下、朝下／起始平放、起始／結束平放夾角分別
為 172.827°、77.954°、1.043°，方向結論沒有改變。此敏感度核對不保證完全
消除接收延遲，也沒有以有利片段取代完整窗口。

## 結論與階段邊界

本次補測取得兩個直立姿態主要重力分量反號的資料證據；測距模組端朝下不再
接近平放，先前 B 姿態缺少的方向證據已補足。起始與結束平放平均方向亦接近。
上述角度是平均向量方向比較，不是角度精度誤差；操作者確認不是獨立姿態真值，
且目前沒有外部姿態量具或獨立基準。

本階段可標示完成：

- 兩次指定 session 的採集、記錄與 cleanup 核對。
- 順序式中文姿態引導的事件完整性。
- 相反直立方向與回復平放的資料觀察。

仍待後續：

- 外部姿態基準與完整精度驗收。
- 車身座標定義及 axis remap 查驗。
- 校正資料保存、載入與跨重啟驗證。
- 道路動態與長時間可靠性。
- BNO055 與警示決策整合。

本階段不實作或執行上述後續工作，也不改寫既有 BNO055、LED、hysteresis 或
同步採集歷史結果。
