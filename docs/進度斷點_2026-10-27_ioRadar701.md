## 下一個精確操作

本次工作已完成，不需要立即重開硬體。若要驗證修正後 live batch ID，必須另行取得
明確硬體測試同意；操作員先確認 IO16→Pi Pin 10/GPIO15 RX、共地、Pin 8/IO17 未接、
TFMini TX 隔離，並確認 ttyAMA0 與 i2c-1 沒有 owner，再在互動 TTY 執行：

```bash
cd /home/topics/Projects/Smart-Rear-Collision-Warning-System
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python \
  -m rear_warning.cli.ioradar701_shadow live \
  --port /dev/ttyAMA0 --baudrate 230400 \
  --i2c-bus 1 --bno055-address 0x29 \
  --duration 30 --confirm-hardware --plain
```

預期：Enter 前零 I/O；Enter 後只讀 radar、讀 BNO055、顯示與記錄 shadow，絕不
控制 LED。風險：程序會獨占 UART、占用 I2C 並切 BNO055 到 NDOF；Ctrl+C/期限後
會嘗試釋放 UART、讓 BNO055 回 CONFIGMODE 並保存結果。這條命令在本次修正後尚未
執行；不要未經確認自行執行，也不要啟用 LED、service、校正或道路測試。
