# 雙感測器同步採集首次實測報告（2026-08-30）

## 範圍與結論

本報告離線核對既有的首次 10 秒 TFMini Plus＋BNO055 同步採集 CSV 與 CLI log。
沒有重新操作硬體，也沒有改寫原始證據。採集 CLI 與 `tee` log pipeline 均成功，
完整 CSV 通過 schema、sequence、因果 timestamp、age、資料品質及摘要一致性核對。

包裝腳本本身不能列為完整成功：其原始最終 exit code 是 1，原因是恢復服務後的
UART holder 確認未通過。後續使用者提供的唯讀查驗確認服務、UART holder 與
BNO055 cleanup 狀態；該補充結果不能回填成腳本當時的成功結果。

CSV 的 `bno055_timestamp` 依 schema 與實作契約是完整 read 成功後的 canonical
wrapper timestamp，且 CSV age 確實由它計算。BNO055 block read 前的原始
measurement timestamp 不在 CSV 或 sample log 中，所以原始證據不足以直接數值
比較兩種 timestamp；本項不能僅憑 CSV 證明「原始值沒有被使用」，而是由既有
schema／程式契約與上述 age 一致性共同支持。

Distance timestamp 首尾跨度為 9.98883411099996 秒，但它不是 sampling elapsed：
sampling 計時從 data-ready 後開始並在 cleanup 前結束，第一列前與最後一列後仍
可有取樣時間。因此 rate 核對採用摘要的 sampling elapsed，不把 initialization
或 cleanup 算入分母。

## 邊界與未完成項目

本次只驗證主機端共同 monotonic timestamp 的因果配對，不代表兩個感測器在硬體
上同時採樣。100% matched 不等於真實量測時間完全同步。這次 stationary bounded
capture 也不證明下列項目已完成：

- 完整四項 BNO055 calibration 或 calibration 保存／恢復。
- 道路動態及長時間可靠性。
- Sensor fusion、closing speed 或 TTC。
- WarningPolicy、警示決策、hysteresis 或 LED 整合的本次驗證。

本次文件更新不更動既有 LED、hysteresis 或 BNO055 歷史實測數據。
