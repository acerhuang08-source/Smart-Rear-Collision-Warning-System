## 已完成：執行中事件標記

現行 SHADOW live 在原本單一程序的 sensor loop 內，以 `select(..., timeout=0)` 非阻塞
輪詢同一互動終端的 stdin。只接受明確且非空的 `:event <detail>`；例如：

```text
:event baseline_fixed_start
:event person_move_start
:event person_move_stop
```

每筆保存到 `events.jsonl`：

```json
{"detail":"person_move_start","kind":"operator","timestamp_seconds":1234.56789}
```

`timestamp_seconds` 是程序讀到完整 stdin 行後立即取得的 host monotonic，不是輸入第一個
字元的時間、wall clock、雷達內部時間或跨機同步時間。事件寫入後會 flush；正常結束、
Ctrl+C、storage/read/close error 仍走原本同一 finally，逐一嘗試關 UART、BNO／bus、
capture files 與 terminal。沒有增加 UART reader、thread、process 或 GPIO adapter。

Replay 會把 source `kind=operator` 依保存時間線寫回新 `events.jsonl`。新 SHADOW 事件
使用 `timestamp_seconds`；既有 standalone ioRadar operator event 的
`elapsed_seconds` 仍可讀。無效 BNO event 仍由保存 BNO 資料重算，不複製冒充。

### 三種不同語意

| 層級 | 現行判定 | 能支持／不能支持 |
| --- | --- | --- |
| 資料有效 | NDOF `0x0c`、SYS_STATUS `0x05`、SYS_ERR `0`、有限值、quaternion norm 0.5–1.5、gravity norm 5–15 m/s² | 可送入目前 sync/fusion；不要求 calibration level，不能稱完整校正。 |
| 完整校正 | `CALIB_STAT=0xff`，system/gyro/accel/mag 都是 level 3 | 只表示 BNO 內部狀態達標；不證明角度外部真值或永久維持。 |
| Profile 相容 | schema/version、canonical hash、sensor label、固定 IDs／firmware、default units／normal power／NDOF、axis map、22-byte write/readback、readiness 與一筆資料有效 | Restore 流程的相容與立即 readback 證據；BNO 無可用唯一序號，仍不能證明同一實體模組或安裝方向未變。 |

本輪沒有讀寫 calibration registers、沒有 restore/export，也沒有把 calibration level 加入
quality gate 或改動 fusion/classifier。

## 設備重新接妥後的可用命令（本輪未執行）

這條命令會在 `--confirm-hardware` 後仍等待互動 Enter；只有操作員再次確認接線、供電、
UART/I²C owner 與風險後才可執行：

```bash
cd /home/topics/Projects/Smart-Rear-Collision-Warning-System
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python \
  -m rear_warning.cli.ioradar701_shadow live \
  --port /dev/ttyAMA0 --baudrate 230400 \
  --i2c-bus 1 --bno055-address 0x29 \
  --motion-period 0.1 --maximum-motion-age 0.2 \
  --duration 120 --confirm-hardware --plain
```

Enter 後會獨占 UART、占用 I²C 並把 BNO055 切入 NDOF；不載入 profile、不建立 GPIO。
執行中按場景輸入上述 `:event` 行，期限或 Ctrl+C 後走既有 cleanup。若未來要載入
profile，需另案決定檔案、sensor label、模組／axis map 相容性及整合生命週期；不能把
獨立 restore 命令默認插入本命令。
