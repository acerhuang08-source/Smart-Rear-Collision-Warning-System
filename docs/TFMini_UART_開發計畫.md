# TFMini UART 測距模組開發計畫

## 一、目前專案狀態

本專案目前仍處於「初始化骨架」階段，尚未實作 TFMini、IMU 感測器融合或碰撞警示邏輯。

### 目前文件狀態

#### `README.md`

目前僅包含專案名稱與基本目標說明。

專案目標為使用以下硬體建立智慧型後方碰撞警示系統：

- Raspberry Pi 5
- TFMini LiDAR 距離感測器
- BNO055 IMU
- LED 警示裝置
- 藍牙語音警示裝置

## 四、TFMini 建議開發架構

建議將 TFMini 測距功能拆分為以下四層：

```text
TFMini UART 通訊
        ↓
位元組串流與封包解析
        ↓
距離、訊號強度、溫度與資料有效性
        ↓
濾波、資料紀錄、監控與未來碰撞判定
```
