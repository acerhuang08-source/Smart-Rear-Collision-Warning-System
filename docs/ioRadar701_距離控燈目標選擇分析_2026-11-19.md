# ioRadar701 距離控燈目標選擇分析（2026-11-19）

## 後續 selector 修正與零 GPIO replay

### 修正範圍

- `RadarTargetSelector.RULE` 由
  `hold-current-else-minimum-hypot-then-id` 改為
  `minimum-hypot-then-id`。
- 每個完整週期都在原 `cycle.targets` 中以
  `(distance_m, target_id)` 選最小者；不再因前一 ID 仍在而無條件保留。
- 候選目標仍只來自 checksum-valid parser frame 與完整雷達週期。壞 checksum
  target 不會進入 selector candidates。
- parser、幾何距離計算、`DistanceThresholds`、`HysteresisThresholds`、TTL、
  LED policy 與 BNO 旁路均未改。
- `target_changed` 與原 `_apply_target_change()` 仍負責清除 target-bound adapter
  狀態並重建 warning stabilizer；重建後立即以同週期新目標距離分類。

selection reason 現在明分：初始最近目標、原 ID 仍為最近、更近 ID
取代仍存在的原 ID，以及原 ID 消失後選新的最近目標。
